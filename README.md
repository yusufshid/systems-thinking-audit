# systems-thinking-audit

A Claude Code Skill that audits AI agents (single-agent or multi-agent) using a systems-thinking framework — leverage points, feedback loops, emergent behavior, and paradigm/mental model — to find structural risks that ordinary code review or security review miss. Built and tested in public.

## Contents
- [`skill/systems-thinking-audit/`](skill/systems-thinking-audit/) — the skill itself: [`SKILL.md`](skill/systems-thinking-audit/SKILL.md) (workflow and report template), [`references/framework.md`](skill/systems-thinking-audit/references/framework.md) (detailed checklist per lens), and [`evals/evals.json`](skill/systems-thinking-audit/evals/evals.json) (test cases).
