# systems-thinking-audit

Belajar dan riset terbuka soal penerapan systems thinking pada AI agent — dibangun secara public.

- [`skill/systems-thinking-audit/`](skill/systems-thinking-audit/) — Claude Code Skill yang mengaudit AI agent (system prompt, deskripsi arsitektur, atau codebase) pakai kerangka systems thinking: leverage points, feedback loops, emergent behavior, dan paradigma/mental model. Diuji dengan eval — lihat [`evals/evals.json`](skill/systems-thinking-audit/evals/evals.json).
